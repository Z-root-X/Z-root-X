# Hi, I'm Zihad

I am a software developer focused on building lightweight, offline-first applications, automation tools, and real-time web solutions. I love creating software that is simple to run, secure, and works seamlessly on local networks without needing complex cloud setups.

## What I'm working with

My primary tools are **Python**, **JavaScript** (and TypeScript), and **SQLite**. I use them to build everything from standalone desktop tools and browser extensions to local database-driven enterprise apps.

*   **Python:** My choice for desktop GUI software (using CustomTkinter), backend scripts, document processors, and working with APIs like Google Gemini.
*   **JavaScript:** What I use for building responsive frontend interfaces (React/Next.js) and lightweight browser extensions.
*   **SQLite:** My go-to local database engine for offline-first systems, running in WAL (Write-Ahead Logging) mode to keep data safe from sudden shutdowns.

## Projects I've Built

Here are some of the key projects I've worked on recently:

### Chuti (ছুটি) — Leave Management System
A local, offline-first application designed for schools and offices to manage directories and leave logs. It runs as a standalone Windows app and can be shared over local office Wi-Fi/LAN so colleagues can connect without requiring cloud hosting.
*   **Built with:** JavaScript (Next.js), SQLite, and Tailwind CSS.
*   **Key features:** Sandwich rules, late-attendance deductions, automatic backup rotation, and printable landscape reports.
*   **Repository:** [zihaaaad/Chuti](https://github.com/zihaaaad/Chuti) (Public)

### EchoScript
A utility that records high-fidelity audio in the background and uses the Google Gemini API to transcribe it concurrently.
*   **Built with:** Dart (Flutter) and Gemini API.
*   **Repository:** [zihaaaad/EchoScript](https://github.com/zihaaaad/EchoScript) (Public)

### VidAI Studio
An AI-powered web tool that takes video links (YouTube, Facebook, Instagram, TikTok) and automatically generates transcripts, summaries, and articles.
*   **Built with:** HTML, JavaScript, and Gemini API.
*   **Repository:** [zihaaaad/vidai-studio](https://github.com/zihaaaad/vidai-studio) (Public)

### VerifEye
A Chrome browser extension that helps you verify if an image you see online is AI-generated by using the Gemini API in real-time.
*   **Built with:** JavaScript (manifest v3) and Gemini API.
*   **Repository:** [zihaaaad/VerifEye-AI-Image-Detector](https://github.com/zihaaaad/VerifEye-AI-Image-Detector) (Public)
